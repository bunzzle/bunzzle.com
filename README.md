# bunzzle.com

The website for [Bunzzle](https://github.com/bunzzle/bunzzle), a self-hosted email delivery engine for apps.

## Development

```sh
bun install
bun run dev
```

`bun run check` type-checks the site and `bun run build` writes the static site to `dist/`. Docs live in `src/content/docs/docs/`.
