Bunzzle is a self-hosted email delivery engine for apps. It delivers straight to recipients' mail servers over SMTP, with DKIM, MTA-STS, IP warm-up and reputation handling built in.

The documentation is being written. Until then, see the [README on GitHub](https://github.com/bunzzle/bunzzle).
